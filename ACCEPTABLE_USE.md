# Acceptable Use

Evil-AI Bench is provided for controlled research, benchmark reproduction, model evaluation, and defensive security development.

By requesting or using the restricted corpus, researchers agree to:

- Use the material only in authorized test environments.
- Avoid probing deployed systems, third-party agents, or real IoT services without explicit written permission.
- Store the executable prompt corpus and raw transcripts securely.
- Avoid redistributing the restricted corpus, raw per-scenario results, or prompt-bearing derivatives.
- Report vulnerabilities responsibly to affected vendors or system owners.
- Cite the benchmark when publishing derived results.

The public repository contains redacted suite metadata and aggregate figures. Full executable prompts are released only through the research-access process.
